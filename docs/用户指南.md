# CopyShare 用户指南

> 文档导航：[故障排查](故障排查.md) · [开发指南](开发指南.md) · [测试与构建](测试与构建.md) · [架构与扩展点](架构与扩展点.md) · [局域网协议](局域网协议.md)

本指南面向日常使用 CopyShare 的用户，说明首次启动、设备连接、剪贴板同步、文件传输和常用设置。遇到异常时，请转到[故障排查](故障排查.md)。

## 1. 使用前准备

- 在需要互传内容的电脑上安装并启动 CopyShare。
- 确保设备位于能够互相访问的可信局域网；访客 Wi-Fi、客户端隔离、VPN 或企业网络策略可能阻止连接。
- 只信任自己确认过的设备。CopyShare 的局域网协议当前不提供端到端加密，不适合直接暴露到公网。

## 2. 首次启动

首次启动会展开主窗口显示设置向导，完成或稍后设置后，后续启动按「设置 → 启动界面」选择的主界面、浮窗界面或浮窗球显示。默认浮窗出现在当前屏幕右上方，点击浮窗中的「主面板」按钮可以展开完整窗口；临时切换窗口不会改变启动界面设置。主界面的「收为浮窗球」和浮窗的「收为浮窗球」会保留同步服务，单击球恢复收起前的界面。浮窗球可拖动并贴近屏幕边缘，右键可打开主面板或隐藏到托盘；关闭「×」仍使用原有的关闭行为。

首次启动向导分为三步：

1. 设置本机在其他设备上显示的名称。
2. 选择文件保存目录，并决定是否自动同步、是否开机启动。
3. 阅读设备连接、双方信任和基本使用说明，保存设置并进入「设备连接」。

向导中选择保存目录只修改草稿，设备名称、保存目录和启动选项会在最后一步统一保存。点击「稍后设置」会保留当前配置并丢弃本次草稿，后续不再自动弹出向导。

随时可从「设置 → 新手指南 → 查看指南」重新查看三步说明。此入口只展示当前配置，不修改设置；阅读完成后可直接前往设备页。

默认文件目录是系统下载目录下的 `CopyShare` 文件夹。以后可以在「设置 → 下载位置」中修改、打开或恢复默认目录。

## 3. 连接并信任设备

### 自动发现

1. 在两台设备上打开 CopyShare。
2. 进入「设备连接」，等待局域网设备出现。
3. 选择目标设备并发起连接。
4. 双方核对设备名称并确认信任。

完成双向信任后，设备再次上线会自动恢复连接。发现设备只表示“看得见”，未完成信任前不会交换剪贴板或文件。

### 手动连接

自动发现失败时，在「设备连接」中填写对方的 IPv4 地址和同步端口。默认同步端口是 `8765`；如果对方修改过端口，请以对方设置页显示的值为准。

连接前可先打开「设置 → 网络诊断」，确认当前局域网地址、监听状态、网络类型和防火墙建议。

## 4. 剪贴板同步

CopyShare 支持以下内容：

| 内容 | 行为 |
| --- | --- |
| 文本 | 复制后同步到已信任设备，并写入剪贴板历史 |
| 截图与图片 | 以图片内容同步，可在历史中预览 |
| 文件 | 先同步文件元数据，接收方确认下载后才保存实际文件 |
| 视频 | 作为文件传输；支持时可在应用中预览 |

在「设置」中可以分别启用或关闭文本、图片和文件同步，也可以暂停整个同步运行时。处理密码、验证码或私人文件前，建议临时暂停同步。

如果启用了重复内容过滤，短时间内再次复制完全相同的内容可能不会重复广播，这是正常的去重行为。

## 5. 文件传输

### 发送文件

在系统文件管理器中复制一个或多个文件。CopyShare 会创建一个传输批次，并向已信任设备发送文件名称、大小和校验信息。

- 一个批次最多 100 个文件。
- 一个批次总大小不能超过 10 GiB。
- 文件内容不会一次性载入内存。

### 接收文件

接收端先显示每个文件的独立记录。点击某一项只下载该文件，不会自动下载同批次中的其他文件。

下载中断后会保留 `.part` 临时文件。网络恢复后可以继续；程序重启时也会根据任务快照和磁盘长度恢复。最终文件只有在大小和 SHA-256 校验通过后才会进入完成状态。

### 常见状态

| 状态 | 含义 |
| --- | --- |
| 等待下载 | 已收到文件信息，尚未选择下载 |
| 传输中 | 正在接收文件数据 |
| 已暂停 | 自动重试结束或用户暂停，可稍后继续 |
| 已完成 | 文件已保存并通过完整性校验 |
| 失败 | 源文件变化、权限、空间、网络或校验出现问题 |

## 6. 历史、收藏夹与常用片段

- 「剪贴板」按文本、图片、视频、链接和文件筛选历史，也支持关键词搜索。
- 历史内容可以置顶或加入收藏夹；清理普通历史不会删除收藏内容。
- 收藏项可以补充标题、标签和备注，并在网格/列表布局间切换。
- 文本收藏可以转换为常用片段；片段支持编辑、置顶和拖动排序。
- 图片与视频预览依赖当前操作系统支持的格式和编码；不支持时仍可打开文件位置。

图片预览底部的工具栏支持上一张/下一张、缩放、重置视图、顺时针旋转、另存和全屏。视频预览支持上一条/下一条、0.25～3 倍速、恢复正常速度、从头播放、另存和全屏播放。切换范围取自当前内容列表中的同类媒体，未下载的视频不参与切换；到达首尾时对应按钮不可用。图片另存为完整尺寸 PNG，视频保持原文件内容。

## 7. OCR、翻译与手机连接

### 图片转文字

在「图片转文字」中粘贴截图、位图或图片文件。OCR 在本机完成：Windows 使用系统 OCR，macOS 使用 Apple Vision，Linux 使用安装包提供的 Tesseract 运行环境。

### 翻译

- Google 翻译无需填写 API Key。
- AI 翻译需要填写自己的 API 地址、API Key、模型和可选代理。
- 翻译文本会发送给所选服务，不要提交不应离开本机的敏感信息。

### 手机临时连接

电脑生成二维码后，手机可在同一局域网通过浏览器临时查看或提交文本。关闭手机会话后，二维码和会话立即失效；不要把二维码发送给不可信人员。

## 8. 设置说明

| 设置区域 | 主要用途 |
| --- | --- |
| 启动与同步 | 开机启动、启动后自动同步、内容类型开关、重复内容过滤 |
| 设备与网络 | 设备名称、同步端口、手动扫描网段、网络诊断 |
| 文件与存储 | 下载位置、完成后打开目录、文件大小限制、缓存管理 |
| 快捷键 | 快捷面板、OCR、翻译、片段和暂停同步的全局快捷键 |
| 通知 | 剪贴板、信任、文件、设备和异常通知及测试通知 |
| 外观与窗口 | 主题、主窗口关闭行为、浮窗体验 |

全局快捷键冲突或注册失败时，CopyShare 会保留原来可用的配置。快捷面板支持方向键选择、`Enter` 复制和 `Esc` 关闭。

### 软件内更新

启动时会静默检查更新，联网失败不会打断启动。在「关于」页点击「检查更新」，发现新版本后点击「下载更新」，查看下载进度和更新说明。下载并通过签名验证后，点击「安装并重启」；文件正在传输或等待自动重连时，需要先完成或暂停传输。

更新包仍由 GitHub Releases 提供，需要能访问 GitHub。首次启用此功能须手动安装带更新功能的安装包，之后可直接在软件内更新；Windows 使用 NSIS 安装版，单独复制的便携 EXE 不作为更新支持范围。更新安装失败可重试，重启失败可手动重新打开软件。

## 9. 日志、隐私与安全

- 「同步日志」记录传输方向、内容类型、设备、大小、状态和错误，不展示剪贴板正文。
- 剪贴板、收藏夹和 OCR 数据默认在本机及已信任局域网设备之间处理。
- 检查和下载更新会访问 GitHub Releases。
- 外部翻译服务会收到用户主动提交的翻译文本。
- 设备信任不能替代网络加密；请只在可信局域网使用。

问题无法解决时，请记录发生时间、两端版本、系统、网络类型、相关状态和可复现步骤，再参照[故障排查](故障排查.md)收集信息。
